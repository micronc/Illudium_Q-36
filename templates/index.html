    Keyboard help for blind researchers

    Use a screen reader (NVDA, JAWS, or VoiceOver) plus these Illudium shortcuts. See docs/ACCESSIBILITY.md for setup.

    • Alt + R — Read last assistant answer / briefing aloud
    • Alt + A — Read ATT&CK ↔ ATLAS panel aloud
    • Alt + I — Read intel file list aloud
    • Alt + S or Esc — Stop speech
    • Alt + 1 — Focus intel corpus
    • Alt + 2 — Focus chat messages
    • Alt + 3 — Focus message box
    • Alt + / — Open or close this help
